        How sign-in is protected

        • Your password is stored only as a salted PBKDF2-SHA256 hash, never as text.
        • 5 wrong attempts lock sign-in from that network for 15 minutes, doubling each time it happens again.
        • Sessions use a random 256-bit token in an HttpOnly, Secure, SameSite=Strict cookie.
        • You are signed out after 2 hours without activity, and after 12 hours at most.
        • Requests from other websites are refused (CSRF protection), and strict security headers block framing and injected scripts.
        • Messages are shown as plain text, so nothing a visitor types can run code here.
