Admin password setup

Creates the value Netlify needs. Everything happens in this browser; nothing is sent anywhere.

At least 8 characters. 10 or more with letters and numbers is much safer. Use a password that isn’t written anywhere else, such as a GitHub README.

  1. In Netlify, open your project → Project configuration → Environment variables → Add a variable.
  2. Key: ADMIN_PASSWORD_HASH. Value: the text above. Keep all scopes and deploy contexts, and save it.
  3. Open Deploys → Trigger deploy and pick the first option. New settings only apply after a new deploy.
  4. Sign in at /login with username cheerwin and the password you just typed. Your contact messages are in the Inbox.
